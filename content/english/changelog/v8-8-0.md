###### Profitec Move 2.0
- Added support for the [Profitec Move 2.0](/profitec-move-2-0/) machine, including brew by weight

###### xBloom/XBRW++ Support
- Import shots from xBloom with the XBRW++ app - thanks to hsus
- Added xBloom as a preparation method
- Import individual brews or batches from compatible apps
- Create missing beans, preparation methods and grinders during import, and see which app an imported brew came from

###### GaggiMate
- Import shots from GaggiMate - thanks to Sartoric
- Optionally write brew notes back to GaggiMate and import the target temperature
- Cancel shot loading, confirm duplicate imports and create missing beans during import
- Improved shot loading, rating import and flow graphs

###### Meticulous
- Import shots independently of the currently selected profile

###### Brew by Weight
- Added a configurable HTTP webhook to stop compatible machines via a smart plug or relay when the target brew weight is reached
- Use predictive stopping that learns from previous brews to compensate for drip-through

###### Brews
- Trim the start and end of brew graphs
- Use the time slider to inspect graph values at a specific moment
- Improved graph axis fitting for reference traces and negative values
- Improved dark-mode colors for graph sliders and annotations
- Long brew notes now wrap within the brew card

###### Statistics
- Exclude archived preparation methods and grinders from statistics
- Filter statistics by time range
- Choose whether bean statistics use the added, roasted, purchased or opened date

###### AI Bean Import
- Add a custom prompt for your AI – thanks to Silas
- Improved compatibility with AI providers that reject the temperature parameter

###### Beans
- Preserve freezing notes and storage type, and clear the previous thaw date when refreezing beans

###### Scales
- Added support for the Futula scale

###### Temperature Devices
- Added support for Ember cups
- Added support for INKBIRD INT-11I-B, INT-11P-B, IHT-2PB, iBBQ and TNT-11-B thermometers

###### Languages
- Added Czech support – thanks to Miroslav
- Added Traditional Chinese support - Thanks to Marcus
- Improved localized date formatting, including Norwegian
- Missing translations now fall back to English

###### Other
- Improved closing reliability of the time-editing popover
- Improved screen-reader labels
- Minor fixes and improvements
